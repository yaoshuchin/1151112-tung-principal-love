# 愛，讓孩子比昨天更優秀

## 董勳遠主任 · 116年國中校長甄選個人品牌網站

- **教育核心信念**：愛，讓孩子比昨天更優秀
- **治校核心標語**：打造一所不怕失敗！讓孩子擁有「韌性與夢想」的學校！
- **座右銘**：今天要勝過昨天；明天勝過今天！

---

### 🌟 網站特色功能
1. **個人經歷與辦學願景**：完整收錄 23 年教育扎根、14 年學務輔導、全國大愛菁師獎、教育部杏壇芬芳獎等殊榮。
2. **四大教育飛輪**：品格賦能、國際翅膀、科技斜槓、閱讀立志。
3. **客製化閱讀體驗**：
   - 字體大小切換：`大`、`中`、`小`
   - 背景色系切換：`淺色`、`深色`、`淡藍`
   - 風格布景主題：`日式`（和風禪韻）、`中式`（翰墨書院）、`西式`（長春藤學府）
4. **治校行動承諾**：晨間校門口迎接、拔尖扶弱、童軍品格服務、跨國交流與書香校園。

- **Icons**: Lucide React
